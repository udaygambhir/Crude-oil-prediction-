# Crude Oil Price Prediction

This project demonstrates how to predict crude oil prices using machine learning techniques such as Linear Regression.

## Project Structure
- `data/`: Contains historical crude oil price data
- `notebooks/`: Jupyter notebook with prediction model
- `requirements.txt`: Python dependencies

## Model
A simple Linear Regression model is trained to predict crude oil prices based on historical data.

## How to Run
1. Clone the repository
2. Install dependencies
3. Run the notebook in Jupyter
